A 4-person pattern with 12 clubs, passing in 3-count. The name is
[Berkeley Y](/patterns/berkeley-y) spelled backwards. It's the same
patterns just that C faces D here. So a 3-count triangle where C+D
take the spot of a single juggler in the triangle.

C throws both of their passes as crossing backdrops.

{{% causal_diagram %}}
3b 3 3 3d 3 3
3d 3 3 3a 3 3
3a"backdrop" 3 3 3b"backdrop" 3 3
3c 3 3 3c 3 3

position A: 0,  100, @C;
position B: 0, -100, @C;
position C: -100, 0, @D;
position D: -200, 0, @C;
